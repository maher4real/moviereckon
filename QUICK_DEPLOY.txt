# 🚀 MovieReckon - Vercel Deployment Quick Reference

## 30-Second Overview

Your app is **production-ready**. All local dev files removed. API handlers configured for Vercel serverless.

## Deploy in 5 Minutes

### 1. MongoDB Setup (2 min)
- Go to https://cloud.mongodb.com
- Create free cluster → Get connection string

### 2. GitHub Commit (1 min)
```bash
git add .
git commit -m "Ready for Vercel"
git push origin main
```

### 3. Vercel Deploy (1 min)
- Visit https://vercel.com/new
- Import GitHub repo
- Add 3 env variables:
  ```
  MONGODB_URI = your_mongodb_connection_string
  MONGODB_DB_NAME = moviereckon
  JWT_SECRET = [generate: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"]
  ```
- Click Deploy

### 4. Final Step (1 min)
- Copy deployed URL from Vercel
- Add env var: `VITE_MONGODB_API_URL = your_deployed_url`
- Redeploy
- Test: curl https://your-url/api/health

## Environment Variables Checklist

## Troubleshooting

| Issue | Fix |
|-------|-----|
| API 404 | Check `vercel.json` exists |
| MongoDB error | Verify connection string in env vars |
| CORS error | Check `VITE_MONGODB_API_URL` matches URL |
| Auth fails | Check `JWT_SECRET` is set |

## Deployment URL Pattern

Once deployed, your app will be at:
```
https://moviereckon-[random].vercel.app
```

Copy this and use as `VITE_MONGODB_API_URL` value.
